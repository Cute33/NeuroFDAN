## SCM 和公式映射

联合处理节点为 `X=(x_c,x_a)`。两分量必须来自同一窗口或同一合成观测。图为 `U→X`、`U→Y`、`X_c→M_c`、`X_a→M_a`、`M_c→M_a`、`M_a→Y`；X 的模态分量不是两个独立处理节点。

- `CNSMediator` 仅接收 `x_c`。局部编码器生成时间驱动，LIF 发放率与同一局部驱动的平均电流共同生成均值和方差。
- `ANSMediator` 仅接收 `x_a,m_c`。对每次采样单独展开 ANS 驱动，在 LIF 电流投影后加入 `W_c m_c+b_c`，广播到所有时间步；未 detach。局部电流残差属于同一中介分支，不绕过中介进入结果模型。
- `no_cns2ans=True` 不创建 CNS 电流映射，只读取 m_c 的形状以确定 S，不读取其数值，不形成梯度路径。这是估计器消融，不是改变真实 SCM。
- `OutcomeHead` 只接收 `m_a,reference`，没有 m_c、当前 x 或标签接口。参考条件信息不代表结构边 `X→Y`。
- U 只存在于生成器和已知分布积分器；学习估计器不读取 U。

联合中介截断所有处理到结果的有向路径；独立外生噪声和无直接 U→M 保证处理到中介无开放后门；联合 X 阻断中介到结果的后门。三个前门条件是结构假设，不是训练结果。M_a 单独也满足前门条件，不宣称联合中介最小。

实际前门计算：

1. CNS 高斯重参数化，采样 `m_c[B,S,D]`。
2. 对每个 `m_c[:,s]` 生成 `mu_a,logvar_a,m_a[B,S,D]`。
3. 从经验配对参考库按当前样本抽取 K 个来源，得到 `[B,K,d_ref]`。
4. 显式展开为 `[B,S,K,D]` 和 `[B,S,K,d_ref]`，不依靠隐式广播。
5. 结果模型输出 `[B,S,K,2]` logits。
6. `softmax(-1).mean(2).mean(1)`，先对 K、再对 S 的**概率**积分。
7. `probs_do[B,2]` 是结果；`logits_do` 仅为该概率的自然对数，不是平均 logits。

`fd_mode=none` 保留同一模块与分层采样，使用第一次样本的 m_a 和事实 g(x) 返回观察预测；完全不调用参考库，不返回伪造的 probs_do。

## 实际接口与默认值

默认 D=64，隐藏维度128，dropout=0.3；训练 S/K=4/16，评估16/64；N_ref=2048；logvar范围[-6,2]；beta=0.001，warmup=10轮；ref_dim=0；类别数2；独立适配器时间步4。

| 模块 | 输入 | 输出 |
|---|---|---|
| CNSMediator | `[B,d_c]` 或可完整展平的 CNS 特征 | 参数 `[B,64]`，样本 `[B,S,64]` |
| ANSMediator | ANS 特征、`[B,S,64]` CNS样本 | 参数与样本均 `[B,S,64]` |
| ReferenceEncoder | 配对 CNS/ANS 特征 | `[R,d_c+d_a]` 或配置的投影维度 |
| OutcomeHead | 显式对齐的 `[...,64]`、`[...,d_ref]` | `[...,2]` |
| ReferenceBank | 配对输入与整数来源 `[N,3]` | 每个当前样本 K 个配对参考及来源 `[B,K,3]` |
| FrontDoorEstimator | 两种模态、参考库/来源、模式和 S/K | 结构化输出及 `[B,2]` 概率 |

已测试旧 GNN 特征接口 `[R,32,32]` 和 `[R,3或4,32]` 的完整展平，参考维度分别1120/1152，结果模型输入为1184/1216。**本阶段不恢复或接管真实骨干**；独立中介编码器无 BatchNorm，避免跨样本统计产生隐式依赖。Phase 2 对接需额外验证真实骨干和归一化策略。

合成默认输入为16+8=24维，参考编码器完整保留24维。8维为压缩对照，64/128维为学习扩维对照；绝不把64维称为本合成任务的压缩表示。`ReferenceEncoder.joint()` 始终可取得投影前的联合特征。完整保留所选特征不证明其是原始输入的充分统计量。

参考库保存原始配对数据，不存可学习原型。默认训练无外部库时从同 batch 抽取其他来源；batch 至少2。显式外部库须由调用方提供合格训练窗口。评估必须显式传库。样本级完整来源三元组支持排除自身，构造与抽样均可排除来源被试。小于容量时使用全部样本，`available_count/used_count/shortfall` 明确记录；抽 K 时有放回。库保存数据可 detach，但可学习 ReferenceEncoder 在每次前向中重新编码，保留其梯度。本阶段不缓存可训练表示，避免参数更新后缓存过期。

## 损失与监督边界

默认 Gaussian 中介的 `frontdoor_loss`：

- 观察损失用第一次完整分层采样的 logits 做未加权 CE。
- KL 对 D 求和；CNS 保留 B；ANS 先保留 B、S，再对 S 平均；两者相加后对 B 平均。
- beta 系数为 `beta*min(max(epoch,0)/10,1)`。
- 无真实干预概率参数时，绝不对 probs_do 使用事实标签监督。
- 只有显式传入归一化 `oracle_probs[B,2]` 才计算真实概率交叉熵；单元测试覆盖这一分支。

正式中介默认是 Gaussian；合成机制是 tanh-Gaussian。学习实验显式配置 `mediator_family=tanh_normal`，采样使用 tanh，条件密度用 atanh 和 Jacobian，不能冒充 Gaussian 真分布。标准正态 KL 接口拒绝 tanh 模式，避免混用先验含义。

学习实验使用合成训练样本中可观测的真实 M_c、M_a：CNS/ANS 条件密度监督及事实结果 CE。ANS 拟合时条件为训练样本真实 M_c，推断时条件为模型采样的 M_c。另拟合普通 X→Y 预测器和额外读取 M_c 的无约束对照。全部只使用训练样本，不读取评估点中介/U/标签，不使用干预真值训练，也不调用旧损失。合成训练学习率0.001、batch128、20轮等设置仅适用于独立实验，不改变真实训练超参数。

float32 中介尾部显式截断至 `(-1+1e-6,1-1e-6)` 供数值密度拟合，截断个数逐配置记录。直接和 oracle 真值使用 float64，不作此截断。合成中介监督不解决真实数据中潜在中介非参数可识别性。

## 三种独立计算

所有真实生成参数保存在 `scm_parameters.npz`，矩阵生成分布为按输入维度缩放的零均值正态。CNS→ANS 矩阵非零。偏置0.2，其他尺度、维度和种子见 config.json。epsilon_y 独立标准正态，经正态CDF变成均匀随机数，与 Bernoulli 概率比较；没有共享噪声。

主计算记录在 `oracle_vs_direct.csv`、`learned_vs_oracle.csv`、`gamma_sensitivity.csv`、`mc_convergence.csv`。`metrics_summary.csv` 对 MAE、概率MSE、期望Brier、期望NLL、校准误差和相对oracle误差均汇总种子均值/标准差；采样、表示、条件独立性、支持距离另有独立CSV。`fit_seconds` 包含同时拟合三个对照网络的耗时，不应解读为单一估计器的纯训练耗时。直接/Oracle两列时间为整批干预点的耗时，逐点行重复记录，不能逐行相加。`phase1_summary.png/pdf` 是独立科学图，误差条为五个种子/随机流的样本标准差。

1. **直接干预**：固定输入，独立重采边缘 U 与两中介噪声，结果 Bernoulli 噪声解析取期望；逐点保存样本均值标准误。
2. **Oracle 前门**：独立生成经验联合参考 X'，解析计算线性高斯观测模型的 U|X' 后验。结果依赖 U 的一维线性投影，用32节点 Gauss-Hermite 积分估计 p(y|m_a,x')；再对 S 个分层 tanh 中介和 K 个参考作平均。不调用直接干预函数。两向一阶标准误仅为近似，不能保证覆盖率。
3. **学习估计器**：训练数据拟合三个条件模型后，调用实际 FrontDoorEstimator，分别与直接/Oracle比较；普通观察预测器和 none 使用相同干预点真值评价，不预设 full 最优。

所有 gamma 使用来自 gamma=0 独立输入总体的同一组干预点。默认16点评价与5个训练种子只能提供有限覆盖，不能推断全支持域均可靠。数值误差收敛采用多个随机种子聚合，不要求单次随机误差曲线严格单调。

## 条件独立性与支持诊断

- OutcomeHead 结构上无 M_c 输入，由签名、梯度和隔离测试检查。
- 在真实生成分布中，用已知 p(Y|M_a,X) 的残差乘 M_c 的8个预先指定坐标构造条件矩统计，报告最大绝对标准化统计量；这是有限个矩的诊断，不是一般条件独立性的充分证明。
- 无约束模型可直接读取 M_c。固定 M_a,X 后，以已知后验密度对 M_c|M_a,X 作椭圆切片采样；两个独立链各40步后比较预测变化。未全局打乱 M_c。该变化是描述性残余依赖诊断，有限链长度不保证完全混合，不把差异称为显著因果效应。
- 交叉参考与当前中介组合的标准化最近邻距离，与独立事实组合比较。该启发式检查不是 positivity 证明；高维有限样本可能仍严重缺支持。
