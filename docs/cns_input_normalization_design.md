## 推荐的单项结构试验

下一项不增加训练轮数、辅助分类头、锚点或新loss。建议只在**CNSMediator进入其encoder之前**加入可关闭的、无可学习仿射参数的LayerNorm。

令z_c=flatten(backbone_c(X_c))，d=12288。每个窗口独立计算

\[
\bar z_i=d^{-1}\sum_j z_{ij},\quad
v_i=d^{-1}\sum_j(z_{ij}-\bar z_i)^2,\quad
\tilde z_{ij}=(z_{ij}-\bar z_i)/\sqrt{v_i+10^{-5}}.
\]

只将tilde_z_c送入原CNS encoder；其余q(Mc|.)、q(Ma|Xa,Mc)、CNS→ANS电流、Gaussian采样和softmax后概率积分保留。ANS入口不加归一化；OutcomeHead及参考编码仍读取原先的输入，不把归一化后的当前CNS特征送入Head。

这是一项可被否定的数值参数化假设：输入的样本内尺度可能使当前中介优化困难，尺度校准可能提高驱动对输入的有效响应。它不是对数据具有真实中介的识别条件，也不证明归一化保留所有生理信息。LayerNorm会消除窗口级的共同平移/整体尺度，这些量可能包含生理或类别信息；因此可能损害性能。更高发放率、更大mu变化或更低采样噪声均不能单独作为通过标准。

拟议实现片段（仅设计，不是当前可运行代码）：

```python
# CNSMediator.__init__，默认开关关闭；无额外参数，也不消耗初始化随机数
self.input_norm = (
    nn.LayerNorm(input_dim, eps=1e-5, elementwise_affine=False)
    if config.cns_input_norm == 'layernorm' else None
)

# CNSMediator.forward，在原distribution调用前
if self.input_norm is not None:
    x_c = self.input_norm(flatten_input(x_c, self.input_dim))
mu, logvar = self.distribution(x_c)
```
